# scansquirrel.org

The ScanSquirrel product front door — one page, one text box (**Squirrel Talk**), and two
exits: sign up free, or Squirrel log in. Static GitHub Pages, no build step. Push to `main`
deploys.

Working on this? Read **`_internal/CLAUDE.md`** first, then
`~/Projects/scansquirrel-web/docs/ARCHITECTURE.md` for the infrastructure.

Not to be confused with `scansquirrel-website` (the `.com` marketing site).
